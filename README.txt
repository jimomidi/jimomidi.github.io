JAVAD OMIDI — PERSONAL ACADEMIC WEBSITE
========================================

FOLDER STRUCTURE
  index.html          Home
  about.html          Bio, education, memberships, languages
  research.html       All research projects
  publications.html   Journal articles, preprints, conference talks
  cv.html             Full experience / teaching / peer review / skills / awards
  contact.html        Contact info + references
  css/style.css        All styling (colors, fonts, layout)
  js/nav.js            Mobile menu toggle
  files/Javad_Omidi_CV.pdf   Your CV, linked from the "Download CV" buttons
  images/profile/      Put your headshot here (see below)

HOW TO ADD YOUR PHOTO
  Save your headshot as:  images/profile/javad.jpg
  It will automatically appear on the About page (and can be reused
  elsewhere). Until the file exists, the site shows a "JO" placeholder.

LOGO
  images/logo.jpg is shown in the header next to your name on every page
  (the <img src="images/logo.jpg"> tag inside the .brand link). It uses
  mix-blend-mode:multiply in the CSS so its white background blends into
  the cream header instead of showing a white box. Swap the file (keep
  the same name) to update the logo everywhere at once.

HOW TO VIEW LOCALLY
  Just open index.html in a browser — no build step or server needed.
  To host it, upload the whole folder as-is to GitHub Pages, Netlify,
  Vercel, or any static web host.

COLORS / FONTS (css/style.css, top of file, :root variables)
  --paper (background), --ink (text), --hematoxylin (accent purple),
  --eosin (accent rose), --navy (dark sections), --sage (secondary accent)
  Fonts: Fraunces (headings), IBM Plex Sans (body), IBM Plex Mono (labels/eyebrows)
